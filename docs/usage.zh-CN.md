# 使用指南

## 启动与状态栏

从应用列表打开 **Oh My Panasonic**，或运行 `pou gui`。

状态栏首页可进入各功能菜单，底部提供挂起、关机、重启和进入面板。隐藏图标在主面板“总览”的状态栏卡片中设置；需要恢复时，在同一位置启用，或运行 `pou tray`。

GNOME 扩展安装或升级后，注销并重新登录以载入新版本。请先保存工作。

## 电源与电池

支持的设备默认采用电池保养模式。拖动充电上限滑块设置目标；数值随拖动更新。

- **立刻充满**：临时允许充到 100%，之后自动恢复保养策略。
- **恢复系统电池管理**：交还充电控制。
- 再次调整充电上限可重新启用保养。

长期接电时，服务会在适当条件下安排维护充放电；不需要手动开始或结束维护。维护可能因负载、温度或供电变化而推迟。

页面显示供电来源、电池功率和预计充满或可用时间。Type-C 协商档位表示供电合约上限，不能作为实时取电功率使用。睡眠和关机限充的支持范围见 [硬件兼容性](hardware.zh-CN.md)。

## 电源策略与散热

在“电源策略”选择省电、均衡或性能预设。电源服务在支持的硬件上应用 CPU、无线及存储节能设置，温度保护优先于性能请求。选择恢复系统策略可交还控制。

光驱供电位于电源策略内。自动模式在光驱空闲且允许安全关闭时断电；使用光盘前可手动开启。挂载、设备占用或恢复中的光驱不会强制断电。

在“风扇与散热”选择标准、静音、性能或自定义曲线。自定义模式可拖动温度曲线节点、调整响应灵敏度和输出百分比。没有可信转速传感器时，RPM 显示未知。

## 网络、显示和触控板

Wi-Fi 支持扫描连接与隐藏个人网络，取消或失败时恢复原连接；企业认证进入系统设置。蓝牙配对时核对双方显示的配对码。

亮度和音量可直接拖动调整。分辨率或缩放变更后，在 GNOME 确认框内保留设置；未确认会自动恢复。

在“圆形触控板”启用圆形滚动并调整速度与方向；选择“恢复原生触控板”可停用。双指手势仍由系统处理。

## 可选人脸认证

安装兼容的识别组件后，进入“人脸解锁”，点击“录入并启用”。根据实时取景完成采集与验证，成功后自动启用。补录可覆盖不同姿态和光照。

登录时先选中账户，锁屏时唤起认证界面。出现识别提示后看向摄像头；失败时可继续使用密码。

桌面权限请求和本地终端 sudo 可分别启用主动确认后刷脸。远程 SSH 不使用此授权路径。人脸匹配不会解密密码保护的 GNOME 登录密钥环；应用首次访问密钥环时仍可能需要账户密码。

主包不安装模型，也不会自动启用刷脸。模型许可、可选构建依赖见 [构建指南](build.zh-CN.md) 和 [安全说明](../SECURITY.md)。

## 升级与卸载

升级时将同一版本主包与兼容包一起安装，命令见 [README](../README.md)。普通升级保留已有设置和录入数据。

移除软件及可选组件，但保留配置：

```sh
sudo apt remove oh-my-panasonic panasonic-on-ubuntu panasonic-on-ubuntu-firmware-dkms panasonic-on-ubuntu-face-gpu
```

没有安装可选组件时，可从命令中去掉对应包名。卸载会停用本项目认证钩子和服务，恢复其拥有的硬件控制。GNOME 扩展退出后，下一次登录完成界面刷新。

需要清除本项目设置时，将 `remove` 改为 `purge`。Facelock 的人脸模板由其自身管理；请先在面板中删除本账户录入，或按 Facelock 文档清理。不要手工删除整个 PAM 配置目录。

## 排障

```sh
pou status
pou doctor
systemctl status pou-battery pou-power pou-optical
journalctl -b -u pou-battery -u pou-power -u pou-optical
```

模块未加载时，检查 `dkms status`、内核头文件和 Secure Boot 签名。不同型号的专用控制不可用时，请勿绕过机型检查。

提交诊断信息前删除账户名、网络名称、IP/MAC、设备序列号及其他个人信息。不要上传人脸图像、模板、密码或私钥。
