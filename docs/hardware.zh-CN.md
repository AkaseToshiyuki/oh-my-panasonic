# 硬件兼容性

当前测试版主要支持 CF-SV7（CFSV7-3L / CF-SV7HD9VS）、BIOS V3.11L22、Ubuntu 26.04.1、Linux 7.0 和 GNOME 50。

| 功能 | 支持范围 |
| --- | --- |
| EC 电池、风扇与光驱 | 限白名单型号及 BIOS；需要可选 DKMS 模块。电池控制还校验完整 SKU |
| 圆形触控板 | CF-SV7 的 SynPS/2 Synaptics TouchPad |
| CPU 功率与温度 | 取决于内核提供的 RAPL、温度和性能计数接口 |
| SSD 电源状态 | ZHITAI TiPlus5000 1TB / ZTA10666 支持 PS0、PS1、PS2，保留 APST；其他型号仅使用可用的通用空闲接口 |
| 状态栏 | GNOME 50 |
| Wi-Fi | NetworkManager 管理的可见、隐藏个人网络；企业证书认证进入系统设置 |
| 蓝牙 | BlueZ 扫描、配对、连接、断开和移除；不同实体外设的兼容性可能不同 |
| 显示 | Mutter 提供的实际分辨率、刷新率与缩放；复杂多屏排列进入系统设置 |
| 人脸 | 兼容 Facelock、红外摄像头和模型；UHD 620 加速需要另行构建可选组件 |

## 可显示的电源数据

电池放电功率、CPU 封装功率、平台能量计和 Type-C 协商功率是不同指标。平台能量计不覆盖所有外围设备，也不是充电接口电表。

CF-SV7 可读取 PD 协商电压、电流和功率上限，目前没有可信的 Type-C 实际输入电压、电流或功率测量接口。原生风扇 RPM 不可用时显示未知；固件反馈百分比不能换算成可信 RPM。电池循环次数只在硬件返回有效值时显示。

CF-SV7 开机充电需要至少 27 W 的 USB-C 电源输出，关机充电需要至少 15 W，见[松下 SV7 开发者访谈](https://news.mynavi.jp/article/20180216-sv7/2)。充电器额定功率不等于当前端口协商功率；多口功率分配、转接设备和协议支持都可能影响可用档位。未充电且协商功率低于要求时，面板显示“PD 供电不足，等待充电”。

SSD 的最大工作功率是设备公布的规格，不代表当前耗电；更低的电源状态可能增加访问延迟。实际续航取决于工作负载和设备。

## 充电与休眠

运行时支持指定充电上限。CF-SV7 可在睡眠或关机期间暂停充电，但不能在关机后从低电量充到任意用户目标再自动停止。需要完整充电时，先在面板选择“立刻充满”。

电池维护仅在满足供电、电量和负载条件时进行；预计可用时间属于估计值。低电量关机等系统保护仍由 Ubuntu 管理。

其他机型、实体光盘、多显示器和外设组合尚未全部验证。请保留密码登录；人脸认证未经过独立的大样本误识率与攻击评估。
